# GCSE Grades System (SQLite)

## Overview

This is a command-line GCSE Grades Management System written in Python using SQLite for data storage.

The program allows teachers to store, search, update, delete and analyse GCSE student results.

## Features

- Insert student GCSE records
- Display all student records
- Search for a student by ID
- Update student records
- Delete student records
- Calculate subject averages
- Calculate overall average
- Display highest and lowest performing students
- SQLite database storage

## Technologies

- Python 3
- SQLite3

## Database

The project stores all student records in an SQLite database.

## How to Run

1. Open the project folder.
2. Run:

```bash
python main.py
```
