# Student Grades Management System (Procedural Python)

## Overview

This is a menu-driven Student Grades Management System written in Python using procedural programming.

The program allows users to store student records, calculate average marks, assign grades, search for students, delete students, and display the highest and lowest performing students.

This project was developed to practise Python fundamentals including functions, lists, dictionaries, loops, validation, and problem solving.

---

## Features

- Insert new student records
- Enter five subject marks
- Validate marks (0–100)
- Calculate average mark
- Automatically assign a final grade
- Display all students
- Search for students by name
- Delete student records
- Display highest performing student
- Display lowest performing student
- Menu-driven interface

---

## Grade Classification

| Average | Grade |
|---------:|-------|
| Below 40 | FAIL |
| 40–59 | PASS |
| 60–79 | MERIT |
| 80–100 | DISTINCTION |
